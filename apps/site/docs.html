Documentation

101 figures, one set of options.

Every figure takes the same props and draws itself in SVG with no dependencies. Install the package, place a figure where your interface needs one, and let state tell it what is happening.

Install

Install the package with your package manager. It is ESM only and has no runtime dependencies.

Terminal
npm i momenta

Importing one figure bundles only that figure. The whole library is about 30 KB gzipped.

Quick start

A figure fills the width of its container at a 5:4 ratio. Give it a width, and it draws itself to fit.

app/page.tsx
import { Upload } from "momenta/react";

export default function Page({ uploading }: { uploading: boolean }) {
  return <Upload state={uploading ? "loading" : "idle"} style={{ width: 240 }} />;
}
main.ts
import { pay } from "momenta";

const figure = pay(document.getElementById("checkout")!, { state: "loading" });

figure.update({ state: "success" });  // when the payment clears
figure.destroy();                     // when the element is removed
index.html
<div id="figure" style="width: 240px"></div>

<script type="module">
  import { upload } from "https://esm.sh/momenta";

  upload(document.getElementById("figure"), { state: "loading" });
</script>

States

Every figure supports the same five states. Wire them to the status your app already has.

StateWhat it showsMotion
idleThe resting picture. The default.Answers the pointer, then holds still.
loadingWork in progress.Loops. With progress, it follows the value instead.
successDone.Settles in green with a tick.
errorFailed.Settles in red with a cross, and shakes once.
emptyNothing here yet.Drawn as a dashed ghost.

Empty states

A figure works as an empty state at 160 to 240 px wide, above a heading and one action. Its resting picture is the illustration; the pointer is a bonus.

no-results.tsx
import { Search } from "momenta/react";

export function NoResults({ onClear }: { onClear: () => void }) {
  return (
    <div style={{ display: "grid", justifyItems: "center", gap: 12, padding: 48 }}>
      <Search state="empty" style={{ width: 200 }} label="No results" />
      <h2>No results match these filters</h2>
      <button onClick={onClear}>Clear filters</button>
    </div>
  );
}

React

Import any figure from momenta/react. Each one renders a <div>, accepts any <div> attribute, and forwards its ref. The module is client-side, so a Server Component can render it directly.

<Upload
  state?: "idle" | "loading" | "success" | "error" | "empty"
  progress?: number        // 0–1, during loading
  count?: number           // where the figure supports it
  intensity?: number       // 0–1, pointer response
  speed?: number           // 0–4
  stroke?: number          // CSS pixels
  marks?: boolean
  interactive?: boolean
  theme?: "auto" | "light" | "dark"
  colors?: { plate?, hi?, edge?, mid?, lo?, ok?, err? }
  label?: string           // or aria-label
  play?: boolean
  {...divProps}
/>

Vanilla

Each figure is also a function named in lower case: upload, pay, signIn. It takes an element and options, and returns an instance.

upload(element: HTMLElement, options?: FigureOptions): {
  update(options: FigureOptions): void
  destroy(): void
}

update merges what you pass. A key set to undefined returns to its default, and a key you leave out keeps its value. destroy removes the drawing and its listeners.

Server rendering

Render one settled frame to a string, for static exports, email, or server-side pages. Include styles once on the page so the colours apply.

server.ts
import { renderToString, styles, receipt } from "momenta";

const html = `<style>${styles}</style>` +
  renderToString(receipt, { state: "success" });

Options

Every figure takes the same options. Anything you leave out keeps its default.

countnumberper figureHow many items the figure holds: rows, cards, coins, digits, seats. Clamped to the figure's range.

Theme

Set these custom properties on a figure or on any element above it. Without them, a figure follows the page: light, or dark when an ancestor has the dark class or data-theme="dark".

PropertyRole
--momenta-plateThe surface each figure sits on. Plates are filled with it to hide what is behind, so set it to your background colour.
--momenta-hiWhat is acting right now: the active object, the figure's focus.
--momenta-edgeSilhouettes.
--momenta-midCreases and secondary lines.
--momenta-loGuides and what recedes.
--momenta-okSuccess.
--momenta-errError.
--momenta-strokeStroke width in CSS pixels.
Colour means something. Figures use colour only for success and error. Everything else is a grey line, so a figure stays readable on any brand.

Accessibility

  • Each figure is an image with a description. Replace it with label, or aria-label in React.
  • With prefers-reduced-motion set, every figure runs at 40% speed and still answers the pointer.
  • Colour is never the only signal: success adds a tick, and error adds a cross.
  • Figures do not take focus. If a figure is interactive for your product, wrap it in a focusable element and describe the action in its label.

Make your own

A figure is a setup that creates springs, and a draw that describes one frame. The scene helpers handle projection, depth and tones, so a new figure matches the rest.

beacon.ts
import { defineFigure } from "momenta";

export const beacon = defineFigure({
  name: "Beacon",
  label: "A beacon on a plinth",
  setup: ({ spring }) => ({ lift: spring(0) }),
  draw(ctx, m) {
    const { scene, state } = ctx;
    const lift = m.lift.to(ctx.hover * 10).value;
    scene.box(0, 0, 0, 80, 80, 6);
    scene.cylinder(0, 0, 6 + lift, 14, 40, state === "loading" ? "hi" : ctx.verdict());
    if (state === "success") scene.check(0, 0, 46 + lift, "ok", ctx.fade());
  },
});

The context

MemberMeaning
stateThe current state.
timeSeconds since mount, scaled by speed. Reading it keeps the figure awake, so read it only while loading.
loop(period)A phase from 0 to 1 that repeats. Keeps the figure awake.
progress(period)The progress option when given, otherwise the same loop.
hover0 when the pointer is away, rising toward 1 near the figure.
ground(z)The pointer projected onto the plane at height z.
fade(seconds)0 to 1 after a state change, for marks that draw in.
shake(amount)A short shake when the state becomes error.
verdict(fallback)"ok" on success, "err" on error, otherwise the fallback tone.
count(fallback, max, min)The count option, rounded and clamped.

Design rules

Every figure follows these rules. They are what make 101 figures read as one family.

  1. One isometric projection. The camera never moves.
  2. One stroke weight. Bold is reserved for marks and progress.
  3. Solids hide what is behind them.
  4. One crease per box, and no shading.
  5. Colour means a verdict. Green is success and red is error.
  6. No words inside a figure.
  7. The idle pose is drawn on purpose and holds still.
  8. Only loading loops.
  9. Empty is dashed.
  10. The pointer is a bonus. A figure works without it.
